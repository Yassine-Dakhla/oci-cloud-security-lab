01

Cloud networking

VCN design, public and private subnets, routing, Internet Gateway and OCI Security Lists.

02

Linux hardening

SSH keys only, root login disabled, unnecessary RPC service removed, unattended security updates and Fail2Ban.

03

Container isolation

The application is bound to localhost and exposed only through a hardened host Nginx reverse proxy.

04

HTTPS & validation

Let's Encrypt TLS, automatic renewal testing, and external Nmap validation of the intended attack surface.
