02 / HEADER ANALYZER

See which browser security policies are missing.

This will become the first live ForgeSec module because it is focused, understandable and useful for website owners.

CHECK

Strict-Transport-Security

Detect whether browsers are instructed to prefer HTTPS for future visits.

CHECK

Content-Security-Policy

Surface whether a CSP is present and explain what problem it is designed to reduce.

CHECK

X-Content-Type-Options

Check whether MIME type sniffing is explicitly disabled.

CHECK

Referrer-Policy

Review whether the site deliberately limits referrer information sent to other origins.
